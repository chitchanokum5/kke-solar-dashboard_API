# ☀️ คู่มือการนำแดชบอร์ดขึ้นระบบออนไลน์คลาวด์ (สำหรับมือใหม่ละเอียดทุกขั้นตอน)

คู่มือฉบับนี้จัดทำขึ้นเป็นพิเศษเพื่อให้คุณสามารถนำระบบแดชบอร์ดแสดงผลไฟฟ้าโซลาร์เซลล์ของบริษัท KKE ขึ้นทำงานบนระบบคลาวด์ออนไลน์ เพื่อให้ทุกคนในบริษัทสามารถเปิดเช็คข้อมูลผ่านโทรศัพท์มือถือ แท็บเล็ต หรือคอมพิวเตอร์จากที่ใดก็ได้ทั่วโลกแบบ **ฟรี 100%** โดยไม่ต้องเปิดคอมพิวเตอร์ทิ้งไว้

---

## 📌 สรุปสิ่งที่จะเกิดขึ้น:
1. **GitHub** จะทำหน้าที่เป็นที่จัดเก็บไฟล์โค้ดของหน้าเว็บและเป็นบ้านให้โรบอทคอยดึงข้อมูลจาก FusionSolar
2. **GitHub Actions** คือโรบอทอัตโนมัติคอยรันสคริปต์ดึงข้อมูลอัปเดตทุกๆ 2 ชั่วโมง
3. **Vercel** คือผู้ให้บริการลิงก์เว็บไซต์หน้าแดชบอร์ดเพื่อให้เราคลิกเข้าดูออนไลน์ได้ทั่วโลก

---

## 🛠️ ขั้นตอนที่ 1: สมัครสมาชิกและเตรียมเครื่องมือ (ทำครั้งเดียว)

1. **สมัครบัญชี GitHub:** 
   * เข้าเว็บไซต์ [https://github.com/](https://github.com/) 
   * กดปุ่ม **Sign up** มุมขวาบน
   * กรอกอีเมลและรหัสผ่านเพื่อลงทะเบียนใช้งาน จากนั้นยืนยันตัวตนในอีเมลของคุณให้เรียบร้อย
2. **ดาวน์โหลดโปรแกรมอัปโหลดโค้ด (GitHub Desktop):**
   * เข้าเว็บไซต์ [https://desktop.github.com/](https://desktop.github.com/)
   * ดาวน์โหลดและติดตั้งโปรแกรมลงในคอมพิวเตอร์ของคุณ
   * เมื่อติดตั้งเสร็จ ให้เปิดโปรแกรมแล้วล็อกอินด้วยบัญชี GitHub ที่สมัครไว้ในข้อ 1

## 📂 ขั้นตอนที่ 2: สร้างคลังโค้ดและอัปโหลดข้อมูล (GitHub Repository)

1. **เปิดโฟลเดอร์โปรเจกต์ในคอมพิวเตอร์:**
   * โฟลเดอร์แดชบอร์ดที่คุณกำลังทำงานอยู่ปัจจุบันคือ `c:\Users\6700530\.gemini\antigravity\scratch\solar-dashboard`
2. **สร้างคลังเก็บโค้ดออนไลน์ผ่าน GitHub Desktop:**
   * เปิดโปรแกรม **GitHub Desktop**
   * ไปที่เมนู **File** (มุมซ้ายบน) > เลือก **Add local repository...**
   * กดปุ่ม **Choose...** แล้วเลือกโฟลเดอร์โครงการของเราด้านบนสุด (`solar-dashboard`)
   * หากโปรแกรมแสดงเตือนว่าไม่มี Git ในโฟลเดอร์นั้น ให้กดคลิกสร้างคลังเก็บโค้ด (เช่น **"create a repository"**)
   * **ตั้งค่าข้อมูลโครงงาน:**
     * Name: `kke-solar-dashboard`
     * **ติ๊กเลือก** `Keep this code private` (เพื่อความปลอดภัย ข้อมูลจะได้เห็นเฉพาะคนในบริษัทของเรา)
     * กดปุ่ม **Create Repository**
3. **ส่งไฟล์โค้ดขึ้นระบบออนไลน์ (Publish):**
   * เมื่อไฟล์ทั้งหมดถูกเตรียมในแอปแล้ว ให้ดูที่ปุ่มสีน้ำเงินมุมขวาบนชื่อ **Publish repository**
   * ตรวจสอบว่ามีเครื่องหมายถูกเลือกที่ `Keep this code private` จากนั้นกดปุ่ม **Publish Repository** สีน้ำเงินอีกครั้งเพื่อส่งไฟล์ทั้งหมดขึ้นคลาวด์ GitHub

## 🔐 ขั้นตอนที่ 3: บันทึกข้อมูลล็อกอิน FusionSolar (GitHub Secrets)

เพื่อป้องกันไม่ให้รหัสผ่าน FusionSolar หลุดออกไปสู่สาธารณะ เราจะเก็บข้อมูลล็อกอินไว้ในกล่องเซฟปลอดภัยพิเศษของ GitHub:

1. เปิดเว็บเบราว์เซอร์ เข้าไปที่เว็บ GitHub แล้วเปิดหน้า Repository `kke-solar-dashboard` ของคุณ
2. ที่แถบเมนูด้านบนของโปรเจกต์ ให้คลิกที่คำว่า **Settings** (รูปฟันเฟือง)
3. ที่เมนูด้านซ้าย ให้เลื่อนลงมาที่หัวข้อ **Security** > คลิกที่คำว่า **Secrets and variables** > เลือก **Actions**
4. คลิกปุ่มสีเขียว **New repository secret** เพื่อสร้างกุญแจสำคัญ 2 รายการดังนี้:

   * **กุญแจรายการที่ 1 (ชื่อบัญชีหัวเว่ย):**
     * ช่อง Name: พิมพ์เป็นภาษาอังกฤษพิมพ์ใหญ่ทั้งหมดว่า `FUSIONSOLAR_USERNAME`
     * ช่อง Secret: ใส่บัญชีของคุณคือ `KKE_API1`
     * กดปุ่ม **Add secret** เพื่อเซฟ
   * **กุญแจรายการที่ 2 (รหัสผ่านหัวเว่ย):**
     * คลิกปุ่ม **New repository secret** อีกครั้ง
     * ช่อง Name: พิมพ์ว่า `FUSIONSOLAR_PASSWORD`
     * ช่อง Secret: ใส่รหัสผ่านของคุณคือ `Chit0986013207`
     * กดปุ่ม **Add secret** เพื่อเซฟ

## ⚙️ ขั้นตอนที่ 4: เปิดสิทธิ์ให้โรบอททำการเขียนข้อมูล (Workflow Permissions)

หากข้ามขั้นตอนนี้ โรบอทจะไม่สามารถนำข้อมูลผลผลิตโซล่าเซลล์มาเขียนบันทึกเซฟทับลงไฟล์แดชบอร์ดของเราได้:

1. ในหน้า **Settings** (ฟันเฟืองด้านบน) หน้าเดิม
2. ที่เมนูด้านซ้ายมองหาหัวข้อ **Actions** (อยู่ภายใต้หมวดหมู่ General) > คลิกเลือก **General**
3. เลื่อนหน้าจอลงมาด้านล่างสุด มองหาหัวข้อย่อยชื่อ **Workflow permissions**
4. ติ๊กเลือกที่หัวข้อ **Read and write permissions**
5. คลิกปุ่ม **Save** สีเขียวด้านล่างเพื่อยืนยันสิทธิ์

## 🌐 ขั้นตอนที่ 5: นำหน้าเว็บออนไลน์ผ่าน Vercel (เว็บเข้าใช้งานแดชบอร์ด)

1. เข้าเว็บไซต์ [https://vercel.com/](https://vercel.com/)
2. คลิกปุ่ม **Sign Up** หรือ **Log In** และคลิกเลือกปุ่ม **Continue with GitHub** เพื่อเข้าสู่ระบบผ่านบัญชี GitHub ของคุณโดยอัตโนมัติ
3. เมื่อเข้าสู่ระบบแล้ว คุณจะเห็นหน้าเว็บหลัก (Dashboard) ให้คลิกปุ่ม **Add New** > เลือก **Project**
4. ระบบจะแสดงรายชื่อคลังโค้ดจาก GitHub ของคุณ ให้มองหาชื่อ `kke-solar-dashboard` จากนั้นคลิกปุ่ม **Import** ด้านหลังชื่อโครงงานนั้น
5. หน้าจอจะแสดงหน้าจอกำหนดค่า (Configure Project) ให้คงค่าเดิมทั้งหมดไว้ (ไม่ต้องเปลี่ยนอะไรเลย) จากนั้นกดปุ่มสีดำชื่อ **Deploy** ด้านล่างสุด
6. รอระบบทำงานสร้างหน้าเว็บประมาณ 30 - 45 วินาที เมื่อสำเร็จหน้าเว็บจะแสดงภาพพลุพร้อมพรีวิวหน้าแดชบอร์ดของคุณ
7. หน้าจอจะให้ลิงก์ทางเข้าเว็บออนไลน์สำหรับใช้งานจริงทันที เช่น `https://kke-solar-dashboard.vercel.app/` 
8. สามารถส่งลิงก์ดังกล่าวให้ผู้บริหารและทีมงานใช้งานเข้าดูผ่านมือถือและคอมพิวเตอร์ออนไลน์ได้ทันทีตลอด 24 ชั่วโมง!

## 🔄 ข้อมูลบนหน้าเว็บคลาวด์จะอัปเดตตอนไหนบ้าง?
* **อัปเดตอัตโนมัติทุกๆ 2 ชั่วโมง:** โรบอทของ GitHub Actions จะรันตัวเองเพื่อล็อกอินดึงข้อมูลใหม่มาอัปเดตไฟล์ตารางและข้อมูลแจ้งเตือนให้หน้าเว็บโดยอัตโนมัติ
* **การสั่งดึงข้อมูลด่วนด้วยตนเอง:** หากต้องการสั่งให้ดึงข้อมูลอัปเดตทันทีโดยไม่ต้องรอ:
  1. เข้าหน้า GitHub Repository ของคุณในเว็บบราวเซอร์
  2. คลิกแท็บเมนู **Actions** (แถบด้านบน)
  3. คลิกเลือกที่หัวข้อ **FusionSolar API Data Sync** ทางซ้ายมือ
  4. มองหาปุ่ม **Run workflow** สีเทาทางขวา คลิกปุ่มแล้วกดปุ่ม **Run workflow** สีเขียวเพื่อเริ่มดึงข้อมูลเรียลไทม์ได้ทันที!
